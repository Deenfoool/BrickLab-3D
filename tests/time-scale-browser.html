Проверка Time Scale на реальном Rapier

Один Brick 2×4 на высоте 900 studs (7,2 м), без соединений. Перед каждым падением создаётся новый мир. Замер по performance.now() и координате rigid body. WebGL не требуется.

QA загружает фактический production import map из текущего index.html, затем production-расширения и Physics UI. Старый V3/V4 runtime map здесь не дублируется.
