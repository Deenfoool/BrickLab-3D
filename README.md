# BrickLab 3D

Первый модуль нового BrickLab рассчитывает посадку деталей Technic и передачу вращения на собранных соосных участках.

```sh
npm test
npm run demo
```

Node.js 22 или новее. Сторонние зависимости для расчётов и тестов не требуются.

- `catalog/technic.json` — профили выбранных мест соединения тринадцати деталей с идентификаторами LDraw. Координаты и длины заданы в LDU, углы — в радианах.
- `src/mechanics/axial.js` — входы отверстий, совместимость сечений, путь вставки, угловые положения посадки и границы движения.
- `src/mechanics/assembly.js` — предпросмотр, подтверждение соединения, занятость участков оси и граф передачи.
- `src/mechanics/gears.js` — зацепление и знаковое передаточное отношение двух внешних прямозубых шестерён.
- `examples/drivetrain.js` — опора и втулка на общей оси, две шестерни и ведомая ось.

`Assembly.previewInsertion` принимает пару идентификаторов портов и относительную посадку. `offset` задаёт положение начала вала на оси отверстия, `direction` — направление вала, `side` — сторону входа. Передайте `{ world: { shaft: { start, axis }, socket: { start, axis } } }` в `previewInsertion` или `connect`, чтобы проверить мировые координаты портов. Редактор проверяет их при восстановлении соединений по сохранённой геометрии. Для уже собранной позы `seated: true` проверяет конечную посадку и занятость участков вала. Обычная вставка также проверяет путь.

`axialTravel` рассчитывает ход подвижной посадки по зазорам до соседей на том же валу. По умолчанию соседи считаются неподвижными относительно вала на протяжении этой операции. Для деталей, которые должны сдвигаться вместе с выбранной посадкой, передайте их порты в `{ coMovingSockets: [{ part, port }] }`. Ядро пересечёт допустимые диапазоны группы.

Для расчёта вращения передайте центры и единичные оси зубчатых венцов в мировых координатах. У остальных деталей ось поворота задаёт основной порт. В примере выходная ось вращается в обратную сторону в три раза медленнее входной. Противоречивая петля возвращает `inconsistent-transmission`.

[Источники и условия использования данных](docs/upstream.md).

## 3D-редактор

Запустите статический сервер из корня и откройте `http://localhost:8000/`.

```sh
python -m http.server 8000
```

«Новая сборка» открывает пустую сцену. В «Примерах» доступен редуктор 8T / 24T. В «Кинематике» потяните за ось или шестерню либо используйте ползунок угла. Для шарнира 41679/41680 выберите одну из половинок, выставьте угол и нажмите «Зафиксировать угол». Сборки сохраняются в браузере, кнопка «Скачать» экспортирует файл `.bricklab`.

### Управление деталями

- ЛКМ выбирает деталь и показывает гизмо в её геометрическом центре. Shift+ЛКМ добавляет или убирает деталь из выделения. ЛКМ по пустому месту снимает выделение.
- G/П включает перемещение, R/К — вращение. S/Ы позволяет потянуть за конец крестообразной оси и выбрать ближайшую длину из каталога (4L, 6L, 8L, 10L). Второй конец остаётся на месте. Предпросмотр показывает сохраняемые и теряемые соединения.
- Вращение по умолчанию идёт с шагом 45°. Кнопка «45°» рядом с инструментом вращения переключает режим на «Плавно». В этом режиме кольца вращаются без угловой привязки, а стрелки при размещении поворачивают деталь по 5°.
- При движении за стрелку привязка соблюдает выбранную ось. Tab перебирает доступные точки стыковки, Ctrl или Command временно отключает привязку.
- Деталь из каталога или буфера следует за курсором. Стрелки поворачивают её, ЛКМ или пробел подтверждает размещение. Esc отменяет текущую операцию.
- Ctrl+C / Ctrl+X / Ctrl+V копируют, вырезают и вставляют. Ctrl+D дублирует. X/Ч, Delete и Backspace удаляют выделение. Ctrl+Z отменяет, Ctrl+Shift+Z или Ctrl+Y повторяет. На macOS можно использовать Command вместо Ctrl.
- ПКМ вращает камеру, Shift+ПКМ сдвигает её, колесо приближает к курсору. F фокусирует камеру на выделении.
