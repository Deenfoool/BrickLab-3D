# BrickLab 3D

Первый модуль нового BrickLab рассчитывает посадку деталей Technic и передачу вращения на собранных соосных участках.

```sh
npm test
npm run demo
```

Node.js 22 или новее. Сторонние зависимости для расчётов и тестов не требуются.

- `catalog/technic.json` — профили выбранных мест соединения девяти деталей с идентификаторами LDraw. Координаты и длины заданы в LDU, углы — в радианах.
- `src/mechanics/axial.js` — входы отверстий, совместимость сечений, путь вставки, угловые положения посадки и границы движения.
- `src/mechanics/assembly.js` — предпросмотр, подтверждение соединения, занятость участков оси и граф передачи.
- `src/mechanics/gears.js` — зацепление и знаковое передаточное отношение двух внешних прямозубых шестерён.
- `examples/drivetrain.js` — опора и втулка на общей оси, две шестерни и ведомая ось.

`Assembly.previewInsertion` принимает пару идентификаторов соединений и выровненную позу. `offset` — положение начала профиля оси от начала отверстия, `direction` — направление оси относительно оси отверстия, `side` — вход со стороны начала или конца отверстия. `connect` записывает успешную посадку. `axialTravel` возвращает продольный ход оси относительно выбранного отверстия с учётом неподвижных упоров на той же оси. Для расчёта вращения передайте центры шестерён и единичные оси в мировых координатах. Положительное направление вращения детали определяется осью первого соединения в её профиле. В примере вращение 8T передаётся на 24T с коэффициентом −1/3.

Область этой версии: осевые посадки и соосные участки с прямозубыми передачами, которые передаются на вход по текущим позам. Поиск кандидатов в 3D, фазировка зубьев, редактор, физические силы и общий решатель шарниров потребуют отдельных адаптеров и следующих реализаций. Для профиля шарнира можно указать положения фиксации, этот режим проверен на синтетическом профиле.

[Источники и условия использования данных](docs/upstream.md).

## 3D-редактор

Запустите статический сервер из корня и откройте `http://localhost:8000/`.

```sh
python -m http.server 8000
```

«Новая сборка» открывает пустую сцену. Выберите деталь из каталога, наведите её на сетку или соединение и нажмите ЛКМ. `R` поворачивает предпросмотр, `Tab` меняет точку стыковки, `Esc` отменяет размещение. Камера вращается СКМ, панорамируется через Shift + СКМ и масштабируется колесом. В «Кинематике» потяните за ось или шестерню либо используйте ползунок угла. Сборки сохраняются в браузере, а «Скачать» экспортирует файл `.bricklab`.

Вкладка «Примеры» открывает редуктор 8T / 24T. Начальный каталог содержит девять деталей Technic. Кинематика рассчитывает вращение осей и внешние прямозубые передачи.

### Управление деталями

ЛКМ выбирает деталь и позволяет потянуть её напрямую в инструменте выбора. Кнопки перемещения и поворота над сценой включают стрелки и кольца.

- G и R начинают перемещение и поворот. X, Y, Z ограничивают действие осью. Число задаёт смещение в LDU или угол в градусах, например G X 20 Enter и R Z 90 Enter.
- ЛКМ или Enter подтверждают операцию. Esc или ПКМ отменяют её.
- Ctrl+C копирует деталь во внутренний буфер редактора, Ctrl+V вставляет её, Shift+D сразу создаёт копию. X или Delete удаляют выбранную деталь.
- Ctrl+Z отменяет действие, Ctrl+Shift+Z повторяет. На macOS можно использовать Command вместо Ctrl.
- При ручных преобразованиях сохраняются связи, которые подходят к новой геометрии. Для присоединения к другой точке выберите «Перестыковать».
