# Editor feedback release

- Catalog demo removed. Cards only after a known PDF/instruction source is found, using the existing archive and per-set discovery. Timeout/network failures hide unconfirmed sets; they are not proof that no instructions exist.
- Sandbox Build Pack accepts test Plus; owned sets remain ineligible. Live payments are unchanged.
- Photo Studio opens from the project name menu and uses the saved visible poses in a separate live WebGL viewport. It supports orbit, zoom, six camera presets, five aspect ratios, lighting, brightness, background, soft shadow, caption and PNG export. Four-view sheet export from the previous workshop tool is not exposed in this new version.
- Collision inspector removed. Drive estimates are simplified and remain approximations. Playback multiplier is separate from physical motor power.
- Right dock starts expanded, ordered instruction, inspector, scene parts. Each panel toggles independently.
- Collaborative rooms are an initial online mode, not persistent shared cloud projects. Sign-in and invite code required. Up to eight distinct members and 2000 parts / 6000 links / 100 belts. Rooms live in one server process; expire after one hour inactive or eight hours maximum and disappear on restart. Joining opens a new local copy. Independent committed edits merge by record identity; conflicting edits stop sync and retain the local copy. Server validates connector occupancy/axis alignment; browser validates geometry and belts before applying. Camera, animation, ghost previews, selection, instruction page and undo history are local. Cursor positions are projected from world space and updated by polling. No guest role, persistent server-side collaboration history, WebSocket transport, or production shared-cloud ACLs yet.
- Before merge: run scripts/check-commerce.sh; browser smoke test project menu, dock stacking, studio, motor speed, catalog and sandbox checkout; two authenticated browser sessions simultaneously add/move/paint/connect/delete, test conflict, cursor alignment, disconnect/rejoin and close. Do not deploy unverified changes.
