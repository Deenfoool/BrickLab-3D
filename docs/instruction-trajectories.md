# Automatic instruction installation paths

Instruction Studio retains manually authored step boundaries. It plans an order within each step by preferring parts with an existing connection to already installed parts. A free part receives a clear illustrative translation. Axial parts use actual saved connector geometry, allowed socket sides, insertion sweep validation and a common direction for every already installed mate. World-space bounds are calculated from the actual loaded model, rotation and reflection. A continuous translated AABB test rejects unrelated obstacles; already connected mating bodies are exempt from that coarse check. This is NOT a mesh-level collision proof and it does not simulate deformation, elastic snap, multi-axis manipulation or gear tooth contact. Special anchor types, conflicting axes, missing geometry, blocked bounds and computation limits are explicitly marked as manual, never animated through an invented trajectory.

The preview is an isolated WebGL scene borrowing the editor's loaded geometry. It provides orbit, step/all playback, pause/restart, 0.5–4× speed, scrub and arrows. Saved model poses are unchanged. Belts become visible when both endpoints have reached their final locations; belt stretching is not simulated. PDF includes up to 12 suggested direction arrows per page and a manual-placement count. AABB checks are capped at 2.5 million across the plan; distance is capped at 1500 LDU; the existing 2000-part/100-step studio bounds remain. Paths are regenerated from model and ordered steps rather than stored as stale geometry.

Acceptance: open a simple axle/bush model and a System brick build, assign stages, verify arrows and actual axial movement, pause and seek, reverse step order and recalculate, add a blocker and check unresolved status. Open an existing large Technic build, inspect special hinges and belts, download PDF and verify arrows and manual warning. Confirm no mutation of the project when closing the studio. Automated tests cover bounds, real connector direction, obstacles, exact endpoints, missing geometry, work budget and deterministic step ordering.
