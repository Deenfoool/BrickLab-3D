# Recognition V9.1 release checklist
## Automated gate
Run the exact PR head with scripts/deploy-community-vps.sh SHA --test-only fix/ducati-instructions. No production data is changed. Unit tests cover silhouettes, split captions, element identity, matching ambiguity, page quantities, local corrections and deadlines.
## Actual browser gate
1. Open Ducati 42238-1 using the official 6661842.pdf; compare cover, actual page count, first and last pages against the original. Check at least ten representative assembly pages, including small pins/axles, long beams, color variants and overlapping parts. Record PDF page, printed step, each visible callout, true design/color/quantity and resulting hint. Report precision (correct / assigned), coverage (correct / manually enumerated), incorrect and missing separately. Do not equate recognized callouts with all parts on the page.
2. Repeat on 42215-1 (two volumes), one image-preview set, and one user-supplied PDF. Navigate fast across pages/volumes while OCR is running; close/reopen the editor; confirm no stale highlights, no stuck recognition state and no PDF replacement. Confirm correct local correction reset and scope.
3. Check hover, click, keyboard focus, touch, reduced motion, narrow panels and unreadable image fallback. Confirm the page list updates when adding/removing a part, without treating total scene usage as step completion.
4. Verify original PDF is preferred over third-party images; simulate a failed PDF request and ensure the alternate image displays without potentially misaligned hints. Verify official paid/server-only policies and unauthenticated access: no client recognition or corrections where access is denied. Original PDF remains viewable where allowed by existing policy.
5. Record cold and warm timing on the same browser and device, and observed errors. Do not declare accuracy or performance targets met without measurements.
## Limits
Inventory scanning has a shared 40-second cooperative budget; individual worker/OCR operations and waiting are bounded. Partial inventory results are not persisted as complete page matches. On timeout, existing exact hints remain usable. Geometry fallback remains conservative and incomplete; no automatic 3D installation. Full browser verification still required.
