# Editor menus and studios — PR 43

The explicitly retained features are Project, Share, View, smart right-click menu, BrickLab Command, Photo Studio, Instruction Studio, live collaboration, Power Flow and Smart Connect. No Module Lab, Design Branch, Blueprint, Mechanics Lab, Explode Studio or Proving Ground is added.

- Project menu: real local part/link/belt counts (not an invented mechanism count), rename, new/copy/open builds, explicit local/cloud save, cloud revision copies, photo and instruction studios, live session. Cloud operations require sign-in, a revision link for history, and an existing publication for copying a public link.
- Right click selects the clicked part; available actions depend on actual rotation solver and axle-length eligibility. Duplicate, mirror, selection, color, groups, isolate, hide and lock. Locks protect committed geometry changes and deletion locally, are saved in scene layers, and may be changed by participants. They are not security permissions. Replacement retains the same ID and refuses replacements that lose existing joints/belts.
- Smart Connect moves one loose unlocked part only. It enumerates up to 12 mechanically validated direct connections, checks occupancy with existing Assembly and allows a ghost preview before apply. It does not invent an intermediate multi-part assembly or do solid-body collision checks.
- Instruction Studio: manual step assignment, reordering, notes, angle, live 3D installation playback, speed, scrub, connector-driven automatic trajectories, cumulative rendered model with previous ordinary finishes dimmed, local PDF download. Up to 2000 parts / 100 steps. PDF pages rasterized; automatic axial installation suggestions and coarse obstacle checks; no automatic step generation, elastic insertion simulation or guaranteed collision-free sequence. See instruction-trajectories.md. Existing instruction reader is unchanged.
- Share: existing BrickLab and publication, LDraw type-1 records with direct colors (external part library required; BrickLab belts and special custom components may not be represented), inventory CSV, PNG via Photo Studio, PDF via Instruction Studio.
- View: separate panels, grid, axes, static connector markers capped at 1500, wireframe, perspective/orthographic cameras, fullscreen, reset. Test Drive uses perspective.
- Ctrl+K command palette lists real registered commands and library parts with keyboard navigation.
- Tests added but not executed from this session. Isolated VPS test runner and actual browser checks are required. No merge or deploy before passing.
