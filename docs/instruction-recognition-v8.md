# Recognition V8 — library-assisted identification
The PDF artwork, exact printed element IDs, and illustrated inventory remain the primary evidence.
- Recover otherwise unknown printed IDs from the local element index only when both the exact ID and its part/color pair match the selected inventory. Bound the number of lookups (12 per page, 128 per session, four concurrent). Never invent missing ID digits.
- Show confirmed PDF results progressively while scanning the inventory. Try the final official volume first, combine up to three final volumes plus the current one when coverage is incomplete, and check the first 12 pages if the tail has no inventory. The displayed PDF is not replaced by auxiliary scans.
- If official PDF matches leave unresolved callouts, lazily load local LDraw models for the set's distinct non-spare part/color pairs. Generate 10 orthographic views per variant and compare four rotations of each normalized image. Compare silhouette, proportions, appearance, and chroma; reject insufficient separation from competing identities. Never override an exact PDF match.
- Geometry fallback is intentionally limited to canonical remote books with all candidate models available and no more than 180 distinct part/color pairs; there is a 35-second cooperative deadline. If WebGL, any required model or angle, or the full candidate universe is unavailable, the original PDF results remain usable. User-supplied PDFs are not automatically matched against the set's 3D catalog.
- Model references and rotated views are reused in the current recognition worker. Synthetic matches are not persisted as audited maps and do not claim a printed Element ID. The cache key includes the complete inventory identity and version.
- Existing Smart Highlight remains compatible with both six- and seven-field region records. Existing commerce policy and release/audit gates are unchanged.
- Synthetic unit tests cover candidate limits, holes, rotated shapes, color separation, ambiguous designs, and exact-ID recovery. Real PDF coverage and browser performance, including Ducati 42238, are not yet measured. This is a conservative fallback, not proof of recognition accuracy.
