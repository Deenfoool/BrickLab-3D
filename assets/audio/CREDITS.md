# Editor sounds

These clips use Kenney audio under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Source files are available through [Open Game SFX Index](https://github.com/Mcamento8/open-game-sfx-index). The editor ships trimmed, normalized mono WAVs.

| File | Kenney pack and source clip |
| --- | --- |
| `snap.wav` | [UI Audio](https://kenney.nl/assets/ui-audio), `click4.ogg`, layered twice to create a double click |
| `place.wav` | [Impact Sounds](https://kenney.nl/assets/impact-sounds), `impactGeneric_light_001.ogg` |
| `tool.wav` | [Interface Sounds](https://kenney.nl/assets/interface-sounds), `select_002.ogg` |
| `tick.wav` | [Interface Sounds](https://kenney.nl/assets/interface-sounds), `tick_002.ogg` |
